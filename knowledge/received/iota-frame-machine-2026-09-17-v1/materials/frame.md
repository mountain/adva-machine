The question is whether the existing frame vocabulary can jointly carry the
minimal iota process and its complex/exponential readings. This profile gives
that question one explicit, replayable finite meaning. It adds no Lisp builtin,
Rust scalar, semantic identity allocator or general Frame API.

## The common frame

A frame binds the pure-iota source process, entry and exit domain policies,
ordered cut basis, complete compact event ledger, declared representation,
complex structure J, cut operator H, metric G, observer O, event clock,
exponential rule, resource ledger and residual. Every chart points to the same
process digest. The braces {}, brackets [] and parentheses () denote declared
construction, space and time roles; this profile does not parse nested brackets.

Iota remains the only primitive source combinator. The symbols e and i live in
this interpretation: e denotes the natural exponential through its coefficient
rule A^k/k!, while i acts as J. Neither is inserted into iota source syntax.
Their simultaneous presence is a typed relationship, not an equality of symbols
or an assertion that one frame has derived its own interpretation premises.

The previous eight-file iota package is a required, pinned dependency already
available at both receivers. Its twelve term/ledger families are freshly
rechecked. Four small families receive the matrix reading: independent iota
contractions, a nested chain, a chain beside an independent event, and a changed
role policy. The native identity/discard/copy observations remain historical
references; this campaign does not repeat those native probes. Full constructor
ancestry remains in the earlier source campaign and is not imported as PSC0 IDs.

## Real paired coordinates for the imaginary unit

Let n be the number of cuts. Work over Q^(2n), with the first block representing
real components and the second imaginary components. Set

    J = [[0, -I], [I, 0]],     J^2 = -I.

The cut graph is the declared undirected adjacency graph of the retained
process. Set H0 = L/(2*d_max), with denominator one for the empty-edge case,
and H = diag(H0,H0). Initially G=I and O=I. The directed evaluator, event labels,
boundary roles, source histories and full-ancestry obligation remain residuals.
This graph observation intentionally forgets some information: the original
and changed-role examples have the same H and different frame bindings.

H commutes with J, is symmetric positive semidefinite and has operator norm
at most one. The positivity argument is the graph sum of squared differences;
the norm bound follows from its absolute row sums and symmetry. The checker
reconstructs the graph, binds its trace to the earlier observation and checks
exact row bounds. These written arguments are not native proof certificates.

Define the real-time and heat generators

    A = -J H,     B = -H.

The exponential readings are U(t)=exp(tA) and T(tau)=exp(tau B). Multiplication
by -i is represented by -J. Substituting t=-i*tau coefficient by coefficient
gives (-J)^k A^k/k! = (-H)^k/k!. The opposite Wick sign already disagrees at
the first coefficient. This is a relation between amplitudes/operators, not
between squared probabilities and not between two evaluation schedules.

The finite checker compares coefficients through order 12. It checks all
coefficients of U(t)^T G U(t)=G through that order, and all bivariate heat
semigroup coefficients of total degree <=12. A truncated polynomial is not
claimed to be exactly unitary. For absolute parameter <=1, the remaining
operator-norm tail is bounded by 3/13!: bound each power by one, use the
factorial tail estimate and the elementary e<3 bound. No finite decimal value
of e or i is used as evidence.

## Carry the observation when changing representation

For y=T x, with an explicitly checked inverse, the target frame contains

    H' = T H T^-1,       J' = T J T^-1,
    G' = T^-T G T^-1,    O' = O T^-1.

The three charts are identity; a nonorthogonal diagonal scaling; and a shear
mixing one real component with its imaginary companion. Thus J itself must be
transported. The checker compares all exponential coefficients under conjugacy,
checks O' U'(t) T = O U(t) coefficientwise, and checks the metric identities.
The approximation bound is preserved in the transported G' norm, not silently
in the target Euclidean norm. The same is true of energy/norm observations.
Keeping the old metric or observer fails concrete negative controls.

Each chart also carries c'(event)=alpha*c(event)+beta with alpha>0. All event
clock equality groups are preserved. Clock readings are event metadata, not
amplitude coordinates: a general change in the amplitude basis does not act on
the clock. Choosing a new clock that separates an independent pair is a new
observer policy, not this passive calibration. No equality between this event
clock and the continuous operator parameter is assumed.

The frame resource ledger is an explicitly stipulated three-unit model account;
its chart positions retain debits 0,1,2. This is a calibration of conservation,
not an executed resource allocation service. Actual matrix work and elapsed
resources, including refused controls, are separately counted and bounded.

## Reproduction

Use Python 3.11+ and fresh output. Both material directories and the expected
new package digest are supplied independently:

    python MATERIALS/check.py --materials MATERIALS \
      --iota-materials PREVIOUS_IOTA_MATERIALS --expect-package SHA256 \
      --stage machine-after-reception --output FRESH_EXTERNAL_DIRECTORY

The contract fixes three runs, two transports, limits and controls. Missing
required inputs yield Unknown; altered bindings or failed identities refuse the
frame. No automatic retry, fuel reset or expansion of the family is allowed.
A successful finite correspondence does not settle nested boundary calculus,
general PSC0 admission, language equivalence, physical Hamiltonians or physical
simultaneity. Those residuals remain part of the frame's meaning.

# Historical bootstrap runtime record

The v0 bootstrap inputs, validation and retained evidence in this directory
record the source and licensing state at that experiment's execution. Their
bytes remain fixed. In particular, `inputs.sha256` is not an automatically
updated inventory of the current checkout, and the frozen packaging script
expects the historical inputs it names.

The current first-party work adopts [Unknown v0.2](../Unknown-LICENSE-v0.2.md),
with scope described in [LICENSING.md](../LICENSING.md). References to private
licensing or authorized collaborators inside the old record describe that
historical state; they do not add restrictions to the current dedication.
Third-party material retains its own terms.

The 2026-09-16 licensing adoption does not claim a new bootstrap-runtime
validation or rewrite the old license hashes. A new distributable bootstrap
bundle would need its own source inventory and validation record.
